# Atlas do escritório corporativo

`corporate-furniture.png` é um atlas original RGBA com 16 móveis, gerado com a
ferramenta integrada **image_gen**, seguindo a skill imagegen. Os recortes de alfa
foram medidos sem modificar a imagem e estão em office-renderer.js.
O desenho mantém as proporções dos recortes e desativa suavização.
Os personagens existentes continuam usando seus próprios sprites.

Prompt usado:

> Use case: stylized-concept. Asset type: production sprite atlas for a top-down pixel-art corporate cyberpunk shooter SANITY.exe. Create ONE square 1024x1024 transparent PNG sprite sheet with EXACTLY 4 columns and 4 rows, each equal cell 256x256. Each cell contains one centered isolated complete object with a 28 pixel transparent margin, no objects or shadows crossing cell boundaries. Camera orthographic true overhead top-down, like detailed handcrafted 16-bit Hotline Miami environment sprites, NOT isometric, NOT 3D. Pixel art with crisp chunky 4x4 pixel clusters, limited colors, dark charcoal outlines, light surface highlights. Furnishings dark corporate graphite metal, warm worn walnut, crimson upholstery, muted teal CRT screens, gray steel; brighter than black floors for readability. Subtle shadows included within cells. All furniture viewed directly from above, same orientation, consistency and no perspective distortion. Exact cell order left to right row by row: row1 (1) office workstation walnut desk with a CRT computer monitor and visible small keyboard, no chair (2) burgundy wheeled office chair from above (3) long oval walnut boardroom conference table with four small papers and two black speakerphones no chairs (4) steel filing cabinet storage block with drawer handles; row2 (5) crimson three-seat sofa overhead (6) leafy potted plant overhead lush dark and bright green pixels in round black pot (7) tall black server rack overhead with red and teal status diodes (8) armored monitoring console desk with three teal screens and compact keyboards; row3 (9) vending machine overhead with red back panel and a small illuminated turquoise control panel (10) coffee counter overhead with espresso machine cups and a sink (11) stacked cardboard archive boxes overhead (12) low metal rectangular storage credenza; row4 (13) small round breakroom table with two mugs no chairs (14) waste bin overhead (15) photocopier with teal glass lid overhead (16) red upholstered armchair overhead. Strict transparent background with alpha. No floor, no room, no grid lines, no cell borders, no text, no labels, no letters, no watermarks, no people, no weapons. Objects individually separated. Readable real furniture silhouettes and intricate pixel details. This is an atlas to crop in 256px cells, not a mockup. Attached map references supply top-down office furnishing density and visual readability only; create original furniture.

A ferramenta entregou um atlas de 1254 × 1254 pixels; o jogo usa os recortes
efetivos medidos, em vez de assumir o tamanho solicitado.
